title: Skills

A skill is a set of instructions an agent loads when a task calls for it. Kind UI's libraries use two.

## Charts

The `kind-ui-charts` skill teaches an agent to choose a chart family for the data, compose it from the public parts, keep keys, units and missing values explicit, and check the result in a browser. It points the agent to the page it needs instead of the whole site.

Install it in agents that support skills:

```bash
npx skills add kind-ui/charts --skill kind-ui-charts
```

Then ask for the chart you need, and name the data, its units and what should happen with zeros and gaps. See Charts' [AI agents guide](/docs/charts) for example prompts.

## UI SDK

Agent UI is built on UI SDK, and its components' `AGENTS.md` tells agents to follow the `ui-sdk` skill. The skill helps an agent build a component UI SDK doesn't ship, from its behaviors, and test its keyboard behavior, focus and ARIA.

It ships inside `@ui-sdk/core`, at `node_modules/@ui-sdk/core/skills/ui-sdk/SKILL.md`, so it always matches the version you installed. To install it in agents that support skills, see UI SDK's [Skills](https://ui-sdk.dev/docs/agents/skills).
