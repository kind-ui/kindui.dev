Kind UI is a family of open-source component libraries. Each library ships as an npm package and as [shadcn](https://ui.shadcn.com) registry items you copy into your project and own.

## Setup

Kind UI components use [Tailwind CSS](https://tailwindcss.com) 4. Add the `@kind-ui` registry to your `components.json`:

```json title="components.json"
{
  "registries": {
    "@kind-ui": "https://kindui.dev/r/{name}.json"
  }
}
```

Then add any component by name:

```bash
npx shadcn@latest add @kind-ui/conversation
```
