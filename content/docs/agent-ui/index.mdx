---
title: Agent UI
description: Agent-operable AI components for React and Web Components, built on UI SDK.
---

Agent UI (`@kind-ui/agent-ui`) gives you conversations, messages, a composer, steps and the other parts of an AI interface, in React and Web Components. An agent can read and operate each component through UI SDK.
